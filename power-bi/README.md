# Power BI Phase

The Power BI phase converts the SQL and Python analysis into an interactive four-page business intelligence dashboard.

## Dashboard Pages

1. Executive Overview
2. Sales and Profitability
3. Customer Insights and RFM Segmentation
4. Delivery Performance and Returns

## Main Analysis

- Revenue, profit, orders, units sold and average order value
- Profit margin
- Sales trends
- Profit by category
- Discount-band profitability
- Customer purchasing behavior
- Repeat purchase rate
- RFM customer segmentation
- Segment-level customer value
- Delivery status
- Shipping-mode performance
- Return rate and return reasons
