# Project Methodology

## Phase 1 — Business Problem

The project evaluates sales, profitability, customer behavior, discounts, delivery operations and product returns for an e-commerce business.

## Phase 2 — Data Preparation

Four related datasets are used. The relationships are customer-to-orders, products-to-orders and orders-to-delivery/returns.

## Phase 3 — SQL Analysis

MySQL is used for structured aggregation, joins, filtering, business KPIs, discount analysis, repeat purchasing, RFM analysis, delivery analysis and return analysis.

## Phase 4 — Python EDA

Pandas, NumPy and visualization libraries are used to inspect the data, validate metrics, explore trends, analyze categories and products, segment customers and investigate delivery and returns.

## Phase 5 — Power BI

Power BI combines the datasets into a relational model and uses DAX measures, calculated columns and a Customer RFM calculated table to create four interactive dashboard pages.

## Phase 6 — Business Insights

Findings from the analytical phases are translated into operational recommendations covering discount control, customer retention, delivery reliability, returns and profitability management.
